Drop each album in its own folder here, named:

  Artist Name - Album Title/

Inside that folder:

  cover.jpg              (or .png / .webp — square, the bigger the better)
  01 Track Name.mp3
  02 Track Name.mp3
  ...

- The leading number just controls play order and is stripped from the displayed title.
- No code changes needed — the app scans this folder automatically.
- Placeholder albums fill any remaining library slots until 12 real albums are in.
